# Lesson Learned Instruction

Lesson records are project-specific. Store each lesson under `.agent_rules/additional/lesson_learned/LESSON-XXXX.md`.

- Review existing lesson files before repeating a workflow.
- Create the next lesson number from the highest existing `LESSON-XXXX` number.
- Use the format `LESSON-0001.md`, `LESSON-0002.md`, and subsequent sequential numbers.
- Record a lesson only when observable experience identifies a mistake, correction, or prevention rule.
- Describe the mistake, the correct approach, and the future prevention rule.
- Use short bullet points.
- Do not overwrite existing lesson files.
