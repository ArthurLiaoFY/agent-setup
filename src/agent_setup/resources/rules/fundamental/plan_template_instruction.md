# Implementation Plan Template Instruction

Implementation plans are project-specific. Store each plan under `.agent_rules/additional/plans/PLAN-XXXX.md`.

- Inspect existing plan filenames.
- Create the next sequential plan number, such as `PLAN-0002.md`, after the highest existing `PLAN-XXXX` number.
- Use `PLAN-0001-my-task.md` only if a descriptive task suffix improves identification.
- If a filename uses a suffix, keep `PLAN-XXXX` as its required prefix.
- Follow the structure defined in this instruction file.
- Write the complete plan in ASD-STE100 controlled English.
- Use short, complete sentences.
- Use one instruction per sentence when practical.
- Use approved technical terms.
- Do not use vague words.
- Do not use ambiguous pronouns.
- Write steps in sequence.
- Use measurable completion conditions.

Use this plan structure:

1. Overview
2. Scope
3. Investigation
4. Proposed Approach
5. Implementation Steps
6. Testing and Verification
7. Risks and Open Questions
8. Completion Criteria
9. Execution Summary
