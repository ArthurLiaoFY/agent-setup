# Task Objective Instruction

The project-specific objective is stored in `.agent_rules/additional/task_objective.md`.

- Read the objective before implementation.
- Keep confirmed facts in the objective file.
- Do not replace the objective from an assumption or an unverified interpretation.
- Update the objective only when the project scope, requirement, constraint, or success criterion is established or validated.
- Explain an objective update briefly to the user.
- Preserve user-managed objective content.
